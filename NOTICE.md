# Откуда взята модель снега

Поведение снега (сугробы-столбики, осыпание, разгребание курсором, порыв ветра, призрак из сугроба)
повторяет веб-демо проекта Snowhush и сделано по его исходнику (snow.js с сайта snowhush.pages.dev).
Код программы написан заново под Windows; бинарники Snowhush не используются.
